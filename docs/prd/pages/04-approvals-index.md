# 04. 审批工作台

## 页面定位

审批工作台是 QuantAgent 中所有高风险建议的人机协同处理入口。它不是事件列表的附属弹窗，而是独立的确认工作面，确保建议动作不会在没有人工确认的情况下被误解为可直接执行。

页面主对象是**审批请求**。

## 页面目标

- 集中展示待处理审批请求。
- 让用户优先处理 AI 推荐度更高的请求。
- 让用户在列表层面就能理解建议、风险和关联事件。
- 支持逐条处理和批量处理。
- 支持回跳到事件详情做证据复核。

## 入口与出口

### 入口

- 顶部导航“审批”
- 事件详情页中的 `进入审批`
- 审计或通知提醒中的审批入口

### 出口

- 去事件详情页
- 去审批详情页
- 处理完后停留本页继续下一条

## 页面布局

建议采用双层结构：

```text
页面头
  -> 顶部统计
  -> 筛选与批量操作栏
  -> 审批列表
```

不建议首版使用三栏复杂操作台，因为重点是快速批量清队列。

## 页面模块

| 模块 | 页面作用 | 是否 P0 必须 | 推荐前端模块 |
| --- | --- | --- | --- |
| 页面头 | 说明审批页职责 | 是 | `features/approvals/components/ApprovalsPageHeader` |
| 统计条 | 让用户知道队列压力 | 是 | `features/approvals/components/ApprovalSummaryBar` |
| 筛选与批量栏 | 快速定位和批量处理 | 是 | `features/approvals/components/ApprovalFilterToolbar` |
| 审批列表 | 承载核心处理动作 | 是 | `features/approvals/components/ApprovalList` |
| 批量确认条 | 展示已选项和风险提示 | 是 | `features/approvals/components/BulkActionBar` |

## 模块详细要求

### 1. 页面头

展示：

- 标题：`审批工作台`
- 副标题：说明这是人工确认链路，不是执行页面

示例：

```text
审批工作台
集中处理需要人工确认的建议动作。批准不等于已真实执行。
```

### 2. 统计条

建议展示：

| 指标 | 作用 |
| --- | --- |
| 待处理数 | 当前队列规模 |
| 高推荐度待处理数 | 优先事项规模 |
| 即将超时数 | 风险压力提示 |

### 3. 筛选与批量栏

#### 筛选条件

| 条件 | 默认值 |
| --- | --- |
| 状态 | 待处理 |
| 风险等级 | 全部 |
| 推荐度区间 | 全部 |
| 来源行业 | 全部 |

#### 排序

默认：AI 推荐度最高优先

可选：

- 即将超时优先
- 最新创建优先
- 风险最高优先

#### 批量处理

首版允许：

- 批量批准
- 批量拒绝
- 批量请求重分析

但 UI 上要明确：

- 只对已选请求生效
- 批量批准不代表真实执行已经完成

### 4. 审批列表

每条审批项必须让用户在不点详情的情况下做初步判断。

#### 列表字段

| 字段 | 必须 | 说明 |
| --- | --- | --- |
| 选择框 | 是 | 支持批量处理 |
| 关联事件标题 | 是 | 告诉用户这条审批来自哪条事件 |
| 建议动作 | 是 | 核心建议 |
| 推荐度 / 可靠度 | 是 | 支持优先级排序 |
| 风险摘要 | 是 | 告诉用户危险在哪里 |
| 触发信息摘要 | 是 | 告诉用户建议是由什么触发的 |
| 状态 | 是 | 待处理 / 已处理 / 已过期 |
| 快捷动作 | 是 | approve / reject / reanalysis |

#### 快捷动作

- `批准`
- `拒绝`
- `请求重分析`
- `查看详情`
- `查看事件`

### 5. 批量确认条

当用户勾选多个审批时，页面底部或顶部出现浮动条：

```text
已选择 4 条审批
[批量批准] [批量拒绝] [批量请求重分析]
提示：批量批准只表示通过人工确认，不代表已完成真实执行
```

## 页面状态设计

| 状态 | 页面行为 |
| --- | --- |
| 无待处理审批 | 展示空态，提示返回事件中心 |
| 有待处理审批 | 显示列表 |
| 部分处理成功 | 保留页面位置，更新对应行状态 |
| 批量处理中 | 显示进度和结果摘要 |
| 某条失败 | 行内错误提示，不阻断整页 |

## 示例

### 示例：审批列表项

```text
[ ] 路透：美国考虑收紧对伊朗石油出口限制
建议动作：观察性做多近月原油
推荐度：78/100
风险摘要：缺少官方二次确认，事件仍可能反转
触发信息：Reuters 首发报道 + 行业分析完成
状态：待处理
[批准] [拒绝] [请求重分析] [查看事件]
```

### 示例：批量处理

用户勾选 3 条同属原油行业、推荐度大于 75 的审批。

批量条显示：

```text
已选择 3 条审批
[批量批准]
说明：本操作只完成人工确认，不放行真实执行
```

## 对应数据建议

```ts
type ApprovalListItem = {
  id: string
  eventId: string
  eventTitle: string
  actionTitle: string
  recommendationScore: number
  riskSummary: string
  triggerSummary: string
  status: 'pending' | 'approved' | 'rejected' | 'expired'
  expiresAt?: string
}
```

## 非目标

- 不做多级审批流
- 不接真实执行控制台
- 不做外部 IM 审批页
- 不把审批工作台做成通用任务中心
